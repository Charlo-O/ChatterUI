# UI reference

`liquid-glass-chat-ui/` is a local clone of
https://github.com/Appllama/liquid-glass-chat-ui.

The app uses the first cookbook, **Fable**, as its visual reference. The clone
is deliberately excluded from the parent Git repository and TypeScript build.
It remains a complete, independent repository for comparison and upstream updates.

To restore it on another machine:

```sh
git clone https://github.com/Appllama/liquid-glass-chat-ui.git extra/liquid-glass-chat-ui
```
